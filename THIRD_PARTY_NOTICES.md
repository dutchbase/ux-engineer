# Third-party notices

UX Engineer does not currently include any files copied or adapted from other projects.

When it does, each borrowed file is listed here with its source URL, exact commit, license, the changes made, and where it is used. The same data is kept in machine-readable form in [`sources.lock.json`](sources.lock.json). Sources whose license is missing or unclear (`none` or `NOASSERTION` in that file) are used as reference only and are never copied into the distribution.
