# Design system

- Font: system UI stack. Body 16px, line height 1.5.
- Colors: text #1f2328, muted #59636e, accent #0b5cad, danger #b42318, surface #ffffff, page #f6f7f8.
- Spacing scale: 4, 8, 12, 16, 24, 32.
- Components: Button (primary, secondary, danger), TextField, Select, Table, Alert (info, error), ProgressBar, Stepper.
- Headings are plain text; no labels above headings.
